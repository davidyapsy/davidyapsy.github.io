First time? Open Settings to enter your OAuth Client ID and Spreadsheet ID — the README walks through getting both in a few minutes.

Your data never leaves your browser except to talk directly to Google's Sheets API. Built with plain HTML/CSS/JS — no backend, hosted on GitHub Pages.

Settings

Expenses are read from whichever month tabs exist (Jan, Feb, ...) — no need to list them. Use one spreadsheet per year and update Year when you start a new one. See the README for the OAuth Client ID and Spreadsheet ID. Stored only in this browser's local storage.
